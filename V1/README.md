# FatigueX V1 (Legacy)

This directory contains the original, initial deployed version of the FatigueX dashboard.

### Tech Stack
*   **Frontend**: Pure HTML, CSS, JavaScript (Static deployment)
*   **Design**: Hardcoded styles, no external frameworks.

### Setup Instructions
Since this is a purely static HTML frontend without a dedicated server, no installation is required.

1. Double-click `index.html` to view the original dashboard interface.
2. Double-click `single_worker.html` to view the legacy single-worker view.
